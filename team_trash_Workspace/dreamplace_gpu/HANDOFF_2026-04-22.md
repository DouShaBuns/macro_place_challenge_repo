## What Has Been Implemented

- `team_trash_Workspace/dreamplace_gpu/optimizer.py`
  - Adds Torch prefiltering before official rerank.
  - Adds optional GPU batch cap via `DP_MAX_GPU_BATCH_CANDIDATES`.
  - Adds `DP_OFFICIAL_RERANK_LIMIT`; `0` means keep `2 * DP_TOP_K_CANDIDATES`
    before official `compute_proxy_cost`.
  - Reuses `ctx.plc` when available to avoid reparsing the official PLC.
  - Skips large-case official local refinement when `num_hard_macros >= 700`
    under adaptive mode.
  - Replaces the analytical congestion-map per-routing-pair Python loop with
    chunked dense tensor masks.
  - Vectorizes SA-style candidate generation by move type when
    `DP_RUN_REFINE=1`.
- `team_trash_Workspace/dreamplace_gpu/placer.py`
  - Parses `DP_TOP_K_CANDIDATES`.
  - Parses `DP_OFFICIAL_RERANK_LIMIT`.
  - Parses `DP_MAX_GPU_BATCH_CANDIDATES`.
  - Keeps `DP_LOG_PROXY_CALIBRATION` disabled by default.
- `macro_place/objective.py`
  - Uses a hybrid overlap checker: scalar loop for small hard-macro cases,
    NumPy vectorized overlap for large cases.
- `team_trash_Workspace/sa_gpu/benchmark_context.py`
  - Stores the loaded official PLC object in `BenchmarkContext.plc`.


## How To Summarize The Full Run

After the full run finishes, compute the average from the JSONL file:

```powershell
$rows = Get-Content team_trash_Workspace/dreamplace_gpu/results/optimized_speed_full_20260422.jsonl |
  Where-Object { $_.Trim() } |
  ForEach-Object { $_ | ConvertFrom-Json }
$valid = @($rows | Where-Object { $_.valid -and $_.overlaps -eq 0 })
$avg = ($valid.proxy_cost | Measure-Object -Average).Average
"valid=$($valid.Count)/$($rows.Count) avg=$avg"
$rows | Sort-Object name | Format-Table name,proxy_cost,wirelength,density,congestion,overlaps,valid,runtime
```

Acceptance target for this speed-first pass:

- `17/17` valid.
- `0` hard-macro overlap on every benchmark.
- Average proxy should stay close to the current README baseline:
  `<= 1.305402` is the initial tolerance (`1.300402 + 0.005`).
- `ibm17` and other large cases should have lower runtime than the slow
  best-quality configuration.
